# Python_lab_2

В ходе данной работы был создан учебный веб-сервис на языке программирования Python, содержащий две уязвимости из OWSAP Top 10, демонстрирующих их эксплуатацию и исправление.

## Реализованные уязвимости
- **A01:2021 – Broken Access Control** (IDOR).
  Последствия: авторизованный пользователь может прочитать чужой профиль, поменяв `id` в URL.
- **A03:2021 – Injection** (Stored XSS).
 Последствия: комментарий сохраняется без очистки и выводится в HTML без экранирования
